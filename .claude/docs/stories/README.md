# Story impact plans

One file per user story in this folder: `<KEY>.md` (e.g. `ONB-012.md`, `LCM-004.md`), written by the story-to-plan skill
from `.claude/skills/story-to-plan/plan-template.md` **before** any code, and approved by a human.

Keys: `ONB-` onboarding, `OFF-` offboarding, `SSO-` single sign-on, `LCM-` lifecycle management,
`INT-` integration framework / integrations, `EXP-` Experience Cloud, `ESM-` platform / Claude setup.

The plan is updated as the story progresses (Built → Verified in sandbox → PR) so reviewers can compare
what Claude intended with what it delivered.
